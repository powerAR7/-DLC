缺氧Mod开发全周期计划书 v0.3

# 一、 核心团队架构

- 主策划：创意需求、资源外协、验收、3D降维美术管线主导。
- 首席架构师（AI）：底层逻辑把控、代码审核、任务拆解、排雷、架构设计。
- 底层开发（Copilot）：高频代码编写、API反查、按工单执行。
- 质检/红蓝对抗（Codex - 暂缓）：等代码突破5000行或进入宇宙DLC时引入。

# 二、 核心战略与底层技术储备

- 美术降维打击：MD/ZB/Blender 制作高精度模型 -> 正交渲染 -> PS描边切图 -> Kanimal打包。
- 动态贴图加载黑科技：通过 Harmony 补丁，在 KAnimGroupFile.LoadGroupResourceFile 时机，使用 File.ReadAllBytes 读取绝对路径的 .png/.bytes 文件，构造 KAnimFile.Mod 强行注册，绕开官方限制。
- 架构升级（当前核心）：彻底抛弃“硬改原版源码”的做法，全面转入“模板基类（Framework）”开发，后续物件全部继承自定义基类，实现低耦合、高扩展。
