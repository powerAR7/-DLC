# 星辰大海（星图大修·黑域纪元）
### 核心目标：重构星图空间结构，引入“黑域”、“时间膨胀”、“虫洞跃迁”与“外围风险带”，打造硬核的深空探索体验。
### 底层架构基准：
**拓扑选择：** 采用拓扑 A（黑域一圈封闭），绝对不采用物理堵墙，防止外部星域所有火箭集体“无路径罢工”。<br>
**黑域判定：** 放弃六边形几何计算，采用 HashSet<string> 硬编码存放黑域内的世界 ID 和 POI ID。<br>
**统一拦截服务：** 建立 WormholeService，集中处理 IsBlocked(cell) 和 NeedsWormhole(from, to)，所有 Harmony 补丁只调该服务。
### 工程实施进度表（按里程碑排序）
**里程碑 1：数据层与黑域定义（隔离测试）**
- [ ] 编写 WormholeService，硬编码黑域集合与虫洞坐标。
- [ ] 配置文件中暂时不接 UI，仅用于后台判定。
- [ ] 防呆测试：确保存档不记录黑域状态，每次读档按世界 ID 重新计算，防止旧档黑域消失。<br>

**里程碑 2： destinations 拦截（不可选）**
- [ ] Harmony Prefix 拦截 ClusterDestinationSelector。
- [ ] 逻辑：若目标 entity 属于黑域，__result = false，让玩家在星图上点不中它。

**里程碑 3：寻路拦截（不可跨越）**
- [ ] Harmony Prefix 拦截 ClusterTraveler（或相关寻路函数）。
- [ ] 逻辑：若终点在黑域内，且起点不在虫洞入口，强制返回“无路径”。
- [ ] 生死线测试：外圈节点之间的路径必须能正常计算，确保外部火箭不罢工。

**里程碑 4：虫洞跃迁（底层搬运）**

**里程碑 5：外围“小行星带”与坠机（风险叠加）**

### 四大死亡陷阱（必须提前防呆）
**外圈罢工：黑域只影响“进不去”，绝不影响“外面互相走”。**<br>
**存档兼容：黑域不存盘，读档重新算。**<br>
**UI 缓存：传送后不刷新 UI，会导致火箭“数字飞了，图标还在原地”。**<br>
**虫洞失效：两端都在黑域、出口是 POI、一端被摧毁，必须写兜底逻辑（退回普通寻路或拒绝）。**
